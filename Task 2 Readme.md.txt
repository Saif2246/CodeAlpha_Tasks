# Task 2: Phishing Awareness Training



## Overview
This project is part of the CodeAlpha Cyber Security Internship.

The objective of this task is to create awareness about phishing attacks and understand how attackers trick users into revealing sensitive information.



## Objective
To educate users about phishing threats, their types, and how to protect themselves from such cyber attacks.



## Topics Covered in Presentation
- What is Phishing
- How phishing attacks work
- Types of phishing attacks
  - Email Phishing
  - SMS Phishing (Smishing)
  - Voice Phishing (Vishing)
  - Fake Websites
- Real-world examples of phishing
- How to identify phishing attempts
- Prevention techniques and best practices



## Tools Used
- Microsoft PowerPoint / Google Slides
- Internet Research
- Cyber Security Concepts
