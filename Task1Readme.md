\# 🌐 Task 1: Basic Network Sniffer



\## 📌 Overview

This project is part of the \*\*CodeAlpha Cyber Security Internship\*\*.



The goal of this task is to build a simple network sniffer using Python that captures live network packets and displays key information such as source IP, destination IP, and protocol type.







\## ⚙️ Features

\- Captures live network traffic in real-time

\- Displays Source IP address

\- Displays Destination IP address

\- Identifies protocol type (TCP/UDP)

\- Lightweight and simple implementation







\## 🛠️ Technologies Used

\- Python 3

\- Scapy library

\- Npcap (Windows packet capture driver)

\- PowerShell / Command Line
